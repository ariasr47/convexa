# @convexa/api

The Rust Axum route graph is the source of truth for HTTP methods, paths, request/response/error
schemas, security, cookies, redirects, and SSE event data. OpenAPI and the checked TypeScript output
are generated from that graph; the named `@convexa/api` functions remain the stable semantic facade.

## Commands

```text
npm run api:contract:generate   # validate and atomically write OpenAPI, parity, schema, manifest
npm run api:contract:check      # offline, non-writing drift/policy/compile check
```

Generation is a contributor command. It does not run at runtime, in a production image, or as a
release/build side effect. After dependencies are installed both commands run offline. Check does
not modify the working tree.

## Results and recovery

The closed result categories are `contract drift`, `missing output`, `zero-operation output`,
`unsupported schema construct`, `incomplete contract coverage`, `invalid OpenAPI artifact`,
`generation tooling failure`, and `generated-client compilation failure`. A clean check prints:

`API contract check passed: generated artifacts match the Rust API contract.`

For drift, run generate, review the generated diff, and commit the matching Rust/OpenAPI/generated
change. Unsupported constructs require changing the contract representation or the pinned toolchain;
do not add an untyped HTTP fallback. Compilation failures identify the repo-relative facade location.

## Generated and manual boundaries

`apps/api/openapi/convexa.openapi.json` is generated from Rust. `libs/api/src/generated/schema.ts`
is generated by `openapi-typescript` and consumed by one `openapi-fetch` client in `lib/client.ts`.
Ordinary HTTP request/response/error wire shapes must come from generated types. The facade may keep
semantic functions, error classes, null/not-found adaptation, coalescing, and caller-facing return
compatibility.

Native browser `EventSource` is the sole manual transport/lifecycle exception. OpenAPI/generated
types still own its path, query, media type, event DTO, pre-stream errors, and meaningful headers;
EventSource owns browser open/consume/close/reconnect, heartbeat, and malformed-event isolation.
Applications import only `@convexa/api`; generated internals are not a public import path.

## Migration and ownership

When migrating a call, preserve method/path/body, same-origin cookie behavior, abort and coalescing,
status/error classes, and absent/null/empty meaning. Do not duplicate a wire interface or object
literal in a facade or dashboard module. The API contract owner maintains the Rust route graph and
`tools/api-contract.mjs`; the shared-client owner maintains the facade and compatibility tests.

The manifest at `apps/api/openapi/generated-artifacts.manifest.json` is the truthful generated-output
index. It has exact path/kind/media/writer/hash entries for OpenAPI, parity, baseline, and schema bytes;
it does not hash itself. The [generated parity artifact](../../apps/api/openapi/parity-coverage.json)
currently reports 52 source-derived operations, 181 material response boundaries, 181 exhaustive
`response-conversion` evidence rows, 87 `direct-http` evidence rows, and 52 operation-complete direct
HTTP scenarios. Those counts are read from the generated artifact; this paragraph is not an endpoint or
evidence catalog to edit by hand. Response-envelope conversion evidence is exhaustive over the material
boundary set. Exact request/response/error/event schemas are enforced separately through the Rust
DTO/`IntoResponses` → deterministic OpenAPI → generated TypeScript compilation graph. Direct HTTP is
risk-tiered but covers every source-derived operation and asserts actual high-risk bodies and effects.

## Rollback and live conformance

Rollback is an atomic repository revert/restoration of the matching Rust declarations, OpenAPI,
generated schema, facade, and manifest. Artifact-only restoration is intentionally rejected as drift;
no persisted user or market data is changed.

The four-call live block in `INTERFACE_CONTRACT.md` is a supplementary live JSON smoke check for a
running service. Operator/research operations remain isolated from trader flows, and no public
OpenAPI or Swagger route is served.

Coverage note: the four-call live conformance block is supplementary; response-envelope conversions are exhaustive, typed schemas are enforced through the Rust-to-OpenAPI-to-TypeScript graph, and direct HTTP evidence is risk-tiered across every source-derived operation.
