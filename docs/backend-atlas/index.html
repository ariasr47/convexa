Demo composition and boundaries

The build selects one complete client composition. The original live route remains a separate Pages → Rust path; the demo uses a browser-local facade and authored scenario.

Build + facade

VITE_DATA_MODE chooses demo or live before React mounts. Demo HTTP uses local Response-compatible handlers; unsupported calls fail closed.

Authored market view

Six symbols × seven expiry selections share one scenario. Normal views populate IV skew, term structure, dealer/context reads, normalized GEX, straddle, unusual positioning and off-exchange context.

Portfolio + playback

Paper book, orders, alerts, settings and sample playback stay in browser-local state. Read-only sample broker holdings remain separate.

Research + guardrails

Six distinct linked Research cases and 60 daily bars load in ticker-local views. Live mode reports those local capabilities unavailable; demo never asserts genuine live status.
