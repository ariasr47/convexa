## Retained limitations

An older visual observation recorded optional provider-derived widgets as unavailable before the S6 population correction; it is historical and does not establish the current normal-fixture state. The strengthened G1 assertions now require the contract's populated normal SPY sample, with any intentional degraded state remaining specific to its affected datum. The production seed loader caches successful scenarios, so this receipt makes no claim that a later network failure invalidates a loaded scenario or that a successful asset can be forcibly refetched. A direct hard refresh can load a deep route using the site's static fallback; an uncached route chunk still requires the normal same-host asset request.
