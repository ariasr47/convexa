Spec · freshness and updates

A note stays true as of its date. The page says when that stops.

Notes are never kept current. Every number carries its date, a real update is a new dated note, and the reader's browser works out each note's state from dates the note already holds. The pre-push check never reads the clock, so it can't fail a push just because a day went by.
