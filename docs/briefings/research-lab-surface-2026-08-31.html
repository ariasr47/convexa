01 — Why this existsYou already pay for the corpus. Until today you could only binge it from a terminal.

Coverage, day tape, replay, and S3 keep all landed as operator tools. They store and classify session books for SPY / QQQ / IWM. Weekly use still meant a CLI session — or reading JSON off /api/_research by hand. The trader app never grew a research browser, on purpose: these bodies are stored research, not live market, and they must not ride a Pages origin.

This slice is the missing weekly surface. One URL. Off the trader shell. Same token as Operator Metrics. Zero Massive on list, open, miss, or coverage.

02 — How to open itThere is no nav item. You type the path.

1

On the dashboard, go to /_ops/research. Same idea as /_ops/metrics: own chrome, not inside the trader shell, not linked from TopNav.

2

Unlock with two fields. API origin is the public API base (Railway), not convexa.pages.dev. Metrics token is the same operator token as metrics — not a trader login cookie.

3

Both live in this tab’s memory. Refresh forgets them. They never go in the URL, sessionStorage, or localStorage.

Pages will 404 research. A document hosted on *.pages.dev is allowed — the page itself can live there — but the research base cannot be a Pages host. Type the API origin. Relative /api/_research is poison: it looks fine on local Vite and dies in production.

04 — Occupancy wordsThree decks. Do not mix them.

WordLives onMeans
present Coverage card only A loadable LiveMassive body for that identity. Fixture, tape, and S3 extracts are never this.
source Books table, printed verbatim Provenance of a stored book (live_massive · fixture · session_tape). Not a coverage cell. Do not read it as present.
kept Flat-file extracts (not this page) An entitled S3 extract occupant. Still not live paid. Still not this URL.
missing / unreadable / not yet due / blocked occupancy Coverage card Closed coverage deck. Weekend uses no-expected framing and does not print pass.
Authorizes: nothing. List, load, and coverage envelopes that this page accepts carry that token. A true vendor call or any other authorize value is an invariant fault — not a digest, not occupancy, not “stale keep last.”

05 — What this is notSame screen, different product, would be a lie.

Not /lab

/lab remains the public instrument-demo hub (Canvas / WebGL, synthetic data, lab-index). Occupying it with paid books would mix a public demo with operator corpus.

Not trader chrome

No TopNav link, no AppShell, no ticker stream, no score-lab HTTP, no morning-note briefing, no JSON export of a loaded book.

Not a Pages research API

Cloudflare Pages still returns plaintext Not Found for /api/_research and /api/_research/*, with or without a token. Weekly use is Railway-direct.

Not a new backend

Empty server product diff. No new path, occupancy class, or seed endpoint. The page talks to list, load, and coverage that already shipped.

06 — When it refusesFailure is a named class, not a blank table.

The page would rather look broken than look like an empty corpus. A few that matter weekly:

You seeIt meansNot
origin-rejected Empty, Pages host, or relative /api origin. No network. Unauthorized. Empty list.
origin-blocked The research base 404s the family (typical Pages Function). No session book. Dashboard host alone.
metrics_unauthorized Token required and missing or wrong. Cookie is not the gate. Origin-blocked. Empty list.
Cross-origin request blocked Classified CORS. Corpus hidden. Cold or warm. Stale keep-last.
session archive not storing Occupancy 500. No books table. No success coverage. No leftover digest. Empty list. Stale list.
Coverage readout unavailable. Coverage GET failed as transport. Books can stay. Prior matrix is not kept. The list stale chip. A grid of missing.
Couldn't refresh — keeping the last list. Same-symbol list Retry failed after a list you are still looking at. Chip switch. Coverage fail. Occupancy 500.

Switching SPY → QQQ hides SPY rows immediately. Retry on the page re-lists the selected symbol and re-fetches coverage — it does not re-open a book. Retry on an unreadable digest re-loads that identity only.
