## The direction

**Curvature Terminal v2** — the same identity (convexity/gamma curvature + broker-terminal honesty),
re-cut so the ticker page reads as **one instrument** instead of a bento of equal widgets.

**What it is for.** Operators and swing traders who live in dark terminals, read dealer gamma structure,
and distrust UIs that overclaim. Numerals are personality; degraded and simulated states are styled
truth, not footnotes. That has not changed. What changed is the shape of the desk.

**What v2 is.** The desk is an instrument, read top to bottom:

**masthead** (symbol, mid, expirations, persona, the one primary action) → **structure field hero**
(the field, the **level ladder**, the **tape trail** and the **structure path** in one panel) →
**read strip** of figure cells → the **AI read brief**, verdict first, laid out wide beside tape /
position / orders → a **quiet context band** that carries its own basis and as-of and never feeds the
score. The landing has exactly **one hero instrument** — the 3D dealer-gamma surface (strike × tenor),
the product's own model drawn in depth, not a decorative illustration.

Layout is design intent recorded for the build, not a rule this file enforces line by line; the
enforceable parts are in **Components / patterns** and **Structural enforcement**. The rendered intent
lives in `design/site/desk.html` (fluid, interactive) and `design/site/library.html`.

**What it deliberately rejects** (with cause — observed failures, not preferences):

| Reject                                                          | Because (evidence)                                                                                                                                          |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GitHub Dark neutrals (`#0d1117`, `#161b22`, …) as “our” palette | Converged baseline before redesign; documented in `docs/design/DESIGN_REVIEW_2026-07-22.md`                                                                  |
| Inter (or system face) as identity                              | Same review; type is Archivo + IBM Plex                                                                                                                     |
| Blue→violet gradient CTAs / marks                               | Skill bans gradient-brand vocabulary; `brandGradient` deleted stage-3                                                                                        |
| Blog cream + Segoe (`#f4f1eb`)                                  | Named slop-tell on a brand asset                                                                                                                            |
| Even sprinkling of accent                                       | Amber is **spent**, not sprinkled; `signal` is quieter on purpose                                                                                           |
| Hue-alone “warning” on brand amber                              | Amber vs warning rule — warnings are burnt orange **+ icon always**                                                                                         |
| Green/red as decoration or on rates / hit-rate tints            | Reserved for **direction** (P/L, flow, gamma sign only). Scope (positions-legs ruling #18): gamma/GEX surfaces keep call-vs-put; position + P&L surfaces tint by **signed-P&L direction only** — never call-vs-put, never position side                                                                                                     |
| A fourth use of the convex arc                                  | Arc is spent in **exactly three** places (mark X, hero curve-draw, arc section dividers)                                                                     |
| **(v2)** Accent-bar stat tiles                                  | A coloured left edge encodes state in hue alone and dies in a black-and-white screenshot; state belongs in the label row and the type register (`design/src/components/figure-cell.mjs`) |
| **(v2)** Hover-only affordances                                 | A control that only appears on hover does not exist on touch or to a keyboard; every hover reveal needs a tap/focus path (`design/src/screens/responsive-spec.mjs`) |
| **(v2)** A “live” chip or pulse on a snapshot surface           | Liveness is a claim. Scanner sweeps, pinned reads and structure snapshots are not streams; the chip and the pulse are gated by a genuinely live stream (`design/CHANGELOG.md`, second-pass fixes) |
| **(v2)** Green/red on status chips, success states or hit rates | Extends the direction reservation to the surfaces v2 adds — a status chip is not a signed number                                                             |
| **(v2)** Chips or labels below the 11px floor                   | v2 adds many chips (connection, provenance, tier, kbd); the floor is what keeps them legible instead of decorative                                           |

### Costs ruled in knowingly

- Dark-first product culture; light scheme exists but dark remains the historical default / anonymous baseline (`tokens.ts` palette comment).
- Structural enforcement (tests that red-build) over prose-only guidelines — new surfaces that fight the inventory fail CI.
- Diagnostic chart series colors are **non-brand** and mode-invariant (`chartCategorical`) — deliberately outside the trader brand palette.
- **(v2) A design source that lives outside the app and must be kept verified.** `design/` can drift from `tokens.ts`. The mitigation is one command — `node design/src/verify-tokens.mjs` — and the rule that drift is resolved **in favour of `tokens.ts`**, never by promoting the mirror.
- **(v2) A wider motion exemption.** Replacing an enumerated exemption with a **class** (data signals) is weaker enforcement than a fixed list. Accepted because the class has a hard predicate — a genuinely live stream plus `prefers-reduced-motion` — and because an enumerated list was already being amended per feature.
- **(v2) A radius migration.** `shape.borderRadius` moves 10 → 12 for panels, which visibly changes every card in the app in one commit. Accepted rather than shipping two radii that differ by 2px.

## Components / patterns

Full prop/state docs for signature pieces: **`design/site/library.html`** (component catalog only —
generated from `design/src/components/*.mjs`, so the catalog and the design cannot describe different
things). `docs/design/DESIGN_SYSTEM.md` documents the **prior** direction and is pending a
retire-or-stub ruling; do not extend it and do not cite it as current.

This section is the **binding short list** agents must not violate:

1. **`ConvexaMark`** — sole wordmark; amber only on the arc-X; no gradient.
2. **Convex arc** — exactly three spends (mark X, hero curve-draw, arc section dividers). Importer set-equality enforced.
3. **Live vs static** — live UI dims + truth markers (e.g. pause) on stream drop; static never fakes live; cold skeleton ≠ offline degrade ≠ “unavailable this cycle” (`[live-vs-static-isolation]`).
4. **Honesty copy** — snapshot/sim/model assumptions visible (window/basis/threshold); sim reads carry SIMULATED framing in-body, not a footnote; no overclaim for anonymous users (`[model-read-carries-its-assumptions]`).
5. **Warning pattern** — `warning.*` + icon always; never brand amber alone for warning.
6. **Focus** — authored `:focus-visible` ring (text-grade amber); no bare `outline: none` without replacement.
7. **Touch** — ≥44px effective targets on coarse pointers.
8. **Mobile terminal** — no horizontal overflow; nav collapses when text nav no longer fits. See 17 for the widths.
9. **`<meta name="theme-color">` follows the active color scheme** (must not stay dark when light mode is on).
10. **Sim trade entry** — one shared `TradeEntryDialog` for sim-only flows (`[single-shared-sim-entry-dialog]`); real-money entry is a separate component if it exists.
11. **Locked intentional deviations** — do not “fix” the **structure field** (`shared/charts/structure-field/StructureFieldCanvas.tsx`) back to horizontal bars (its diverging form is owner-locked); do not collapse mid + last-trade into a single price without an amendment. *(Amended 2026-09-05, phase 2: the rule named “the GEX chart” — the Recharts `GexProfileChart` — which the Canvas2D structure field superseded and which was deleted this phase. The lock's substance is unchanged and the second clause is kept verbatim: the masthead redraw is precisely when that collapse gets proposed for space.)*
12. **Figma “Design Reference” is retired** as authority (owner 2026-07-22) — it encodes the old palette; `tokens.ts` only.
13. **(v2) Figure cell replaces `StatTile`.** No coloured accent edge. State lives in the **label row** (caps label, ⓘ, and a live dot **only** when the value comes from the stream) and in the **type register** (Mono = a figure **traced to Convexa's computation or to a record the trader entered**; Sans with a dotted rule = asserted but untraced). *(Widened 2026-09-07, phase 3 — OWNER ruling D-D: a number the trader typed is traced to a record Convexa holds, so risk inputs, sim entry and alert thresholds render Mono with **no** dotted rule and the `${assertedBy} · untraced` caption is unreachable for them. The clause read as computation-only, which would have dressed the trader's own figure as an outside assertion.)* Offline keeps the **last known value dimmed (`extrasFor(theme).textDim`), with a pause marker,** and says so **when a retained value exists**; when none does, the cell renders a not-a-number member with the pause marker and **no** "last known" words. The clause is data-driven, never a fixed caption (amended 2026-09-03, ruling 2). *(Corrected 2026-09-09, PR #46 CI repair §A: "50% opacity" MEASURED as a WCAG failure everywhere it shipped (`color-contrast`, serious, 2.21–4.34:1) — opacity composites the foreground with whatever sits behind it, so it can never carry a contrast guarantee. Dimming is a SOLID colour token now (`textDim`, ≥4.5:1 on every real surface, both schemes); the pause mark stays the non-colour cue, unchanged. See Amendments.)* A member of the closed not-a-number vocabulary renders as 15px **Sans**, never as a figure. Container steps: 20px → 17px under 360px of panel width → 15px under 280px. Source: `design/src/components/figure-cell.mjs`.
14. **(v2) Level ladder** — the structure levels sorted by price (call wall, mid, max pain, gamma flip, put wall) with distance **from the levels anchor (`gex_spot ?? price`), stated once in the ladder header**, in the last column; the mid is the **only** live row (and carries no distance of its own). *(Amended 2026-09-05, phase 2 — DELEGATED P3: the rule said “distance from mid”, but the shipped anchor is `gex_spot ?? price` (`_kit/distanceToLevel.ts:11-14`). 15. **(v2) Read strip** — one horizontal strip of figure cells (opportunity, net DEX, IV/HV, IV rank, chain vol/OI, skew, term structure, off-exchange) under the hero. It is figure cells, so rules 13 and 24 apply to it unchanged; it may scroll sideways as a deliberate rail (17).
16. **(v2) AI read brief** — **verdict first**, then risk, then rationale. The **verdict word is the only amber-rendered TEXT in the panel, in every state** (Archivo display). Amber that is **not** text is a **closed list of three**: the authored `:focus-visible` ring (rule 6, a system-wide affordance), the in-flight progress indicator while a request is actually running (mutually exclusive with the verdict word), and **the fill of the state's ONE primary action** (`primary.main`, the fill/UI amber grade). At most **one** primary-action fill is mounted in any single state — the rule's teeth are **cardinality, not exclusion**. *(Amended 2026-09-05, phase 2 — DELEGATED P2, then amended again at GATE Z by owner ruling. Read as “no other amber pixel” the rule is unsatisfiable against rule 6's amber focus ring, and GATE Q proved four primary CTA fills legitimately spend the fill grade this canon's own palette table defines. Amber stays spent, not sprinkled.)* The four risk fields (max risk · invalidation · entry · target) come **before** any prose, each carrying its grounding line — a check for traced, a dash plus the Sans register for the model's own number, **never colour**. **Ten named states**, none of which may collapse into another: *idle · loading · produced (trade) · produced (no trade) · stale · cooldown/daily cap · signed out · add a key · **request failure** · full-analysis drawer*. **Request failure** renders its own named line (“AI unavailable — try again”) and **never** as idle or as a no-trade verdict; a failed refresh over a produced read leaves that read pinned and readable. **Composition:** *stale*, the *full-analysis drawer* and the *quiet-gate annex* (`no_edge` over a produced result) **compose over** a produced read rather than being exclusive peers — the same clarification shape rule 18 took. **Dispositions:** `no_edge` → the quiet-gate annex; `superseded_inputs` / `stale_at_generation` / `stale_newer_snapshot` → *stale*; `incomplete_trade` → the produced body. *(Amended 2026-09-05, phase 2 — DELEGATED P4: the canon lagged the code, the same shape ruling 3 corrected for rule 24. The failure copy already shipped; this names it.)* (`design/src/screens/ai-read.mjs`). `no_trade` is a complete, correct answer, not an error. **Stale is a warning strip with the icon**, in-body, never a footnote. The panel carries a one-line grounding summary and the folded Why; the itemized grounding breakdown with counts, the cited contract, the analyst prose and the as-sent inputs live in the drawer — the panel never grows to hold them. Under **768px** the whole brief becomes a **bottom sheet** with a peek row carrying the verdict, over the `scrim` token.
17. **(v2) Six breakpoints + container queries, no horizontal overflow.** Bands per the Tokens table. Checked widths: the suite (`apps/dashboard-e2e/src/e2e/no-overflow.spec.ts`) enforces **393** (both schemes), **900** and **1280** today; **834** was added at build in **phase 1** and **900 stays** (the MUI `md` band is still where the tables are densest). The design renders the phone at **390**, so the narrower of 390/393 is the binding floor and both must be clean. Grids use `minmax(0, 1fr)`; long strings ellipsize or wrap; only deliberate rails (read strip, quick symbols, desk strip, settings tabs) scroll sideways. Safe-area insets are padded, not ignored.
18. **(v2) One connection chip per page**, with exactly six states and no invented seventh: **live** (signal dot + mid, only while the stream is genuinely live) · **closed** (neutral, names the mid it is showing) · **overnight** (warning + icon) · **no ticks** (warning + icon) · **offline** (warning + icon, "reconnecting…") · **replay** (outline, names the session). Source: `design/src/components/chip.mjs` `CONNECTION`. A second **connection-chip** claim anywhere on the same page is the failure this rule exists to stop. **This rule is chip-scoped** (clarified 2026-09-03): the per-figure live dot rule 13 mandates is a provenance mark on one value, not a second page-level liveness claim. Read literally against rule 13 the two contradicted, which is why the scope is now stated. Before the first stream fact the chip slot carries a **wordless placeholder** and then latches irreversibly to one of the six — the visible absence of a claim, not a seventh state (ruling 1).
**Demo-mode exception (2026-10-07, portfolio-demo-platform):** an authored synthetic scenario replaces the page connection-chip slot with persistent text-visible **Demo · sample data** and its explicit scenario as-of date. This is provenance, not a seventh connection state. All six original states remain the live-mode vocabulary.
