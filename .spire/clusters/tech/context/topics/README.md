# Topic files (on-demand memory depth)

> Files in this directory are **not** loaded at every boot. Link them from
> `../INDEX.md` so the conductor and roles know they exist. Prefer short, single-topic
> notes over dumping the whole product here.

## Conventions
- One concern per file: e.g. `domain-math.md`, `ops-runbook.md`, `integrations.md`.
- No secrets, credentials, or machine-only absolute paths.
- Binding product rules still graduate through `DECISION_LEDGER.md` → `PROJECT_CONTEXT.md`;
  topic files hold **descriptive** depth, not a second law book.
- Update the INDEX pointer when you add, rename, or drop a topic.

## Starter
Create topic files next to this README when product lore outgrows a PROJECT_CONTEXT section.
