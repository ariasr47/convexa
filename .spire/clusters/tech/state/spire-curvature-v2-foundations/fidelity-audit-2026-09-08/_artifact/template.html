The four site surfaces at 1280

Why it is still like this

The three phase SPECs cite design/site/*.html 0 / 0 / 0 times and design/src/screens/*.mjs 0 / 2 / 1 times; the three QA reports cite neither. Every acceptance criterion is a behaviour; none reads "matches <screen>.html at 1280 / 834 / 390, measured". The canon files layout as "design intent recorded for the build, not a rule this file enforces line by line". So the pipeline verified what it was asked to verify — and composition was never on the list. The review said this on 2026-09-07; the counts are the receipts.

Recommendation

Every remaining contract that touches a surface carries one composition row per surface — matches design/site/<screen>.html at 1440 / 1280 / 834 / 390, measured — with this audit's harness as the instrument. It writes the same PNG and JSON census used here, so a QA row can quote a height instead of an impression.

On the open decision

At 1280 the desk is 1,476 px taller than the design after the hero repair, and that remainder is F1 + F2 + F3 + F4 — the masthead, the read strip, the tape-and-plan grid and the context band. The hero closed about 740 px of a ~2,000 px gap; the rest of /ticker is the larger half. The evidence supports the handover's recommendation: one more lane on the same rules as the hero repair, scoped to those four regions, before phase 4 — with F9 folded in.

Method, limits and how to re-run

App side: the production bundle (apps/dashboard/dist, rebuilt from c0f05063+3) served by http-server, driven by the quality gates' own strict fixtures. Design side: design/site/*.html, generated 2026-09-04 from a design/src that has not changed since except verify-tokens.mjs. Fonts: the app's self-hosted Archivo / Plex files were served to the design page in place of its Google Fonts link, so both sides shape text with the same bytes. Widths: 1440 · 1280 · 834 · 390 — the design's artboard registry. Capture: scroll through to mount everything, wait for the connection chip to read live, freeze rAF, full-page PNG at DPR 1, a census of every region, computed-style probes of panel chrome, a font-family census.

Desk data: desk-real-* render the real SPY bundle the local API served at 10:59 UTC (483 strikes; market_state carries term structure, IV rank, straddle, dealer flow, market context) plus a contract-complete stream event. desk-trade/idle-* use the strict fixture (empty field, empty band) with the AI read driven to the produced-trade state.

Limits: the vendor feed was reconnecting with growing backoff during the run and /api/ticker/SPY stopped answering, so nothing here is against the live backend; the real bundle is a pre-market snapshot. The fixture scan's sweep sentinel makes the scanner say Structure as-of 496527h. No account was created and no password typed; auth-gated pages use the fixtures' signed-in session.
