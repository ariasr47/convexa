# openapi-router-dependency-replacement — implementation plan

**Goal:** replace `utoipa-axum` with one repository-owned Axum/utoipa registration graph while
preserving the existing 52 operations, 181 response conversions, 87 direct-HTTP outcomes, generated
contract bytes, shared-client behavior, and four-call live interface.

**Architecture:** local `ContractRouter<S>` transactionally produces Axum and OpenAPI from one package
per handler/`__path_*` pair. A history-anchored pre-edit oracle pins artifacts, metadata, and executed
IDs; normal gates check it, pairing, the all-52 compile receipt, and package absence. This is
backend/shared tooling only, with no frontend implementation or behavior change.

**Tech stack:** Rust 2021; Axum `0.8.9`; utoipa `5.5.0`; Serde; Tower; Node `>=24`; Cargo deny;
Nx 23; Vitest; Docker; PostgreSQL 17; GitHub Actions.

**Spec:** `.spire/clusters/tech/contracts/openapi-router-dependency-replacement/SPEC.md`

  Preserve B7a `96aad2b` as its child; B7b is an append-only child of `96aad2b`. Never amend, squash,
  rebase, reset, or recreate history.

  path, or a broad `.spire/**` path. Leave unrelated `.claude/**`, `.codex/**`, `.grok/**`, provider

  `utoipa::openapi::OpenApi`. It has no `AppState`, service, store, config, vendor, worker, listener,

  generated manifest.

  `incomplete contract coverage`; only completed byte comparison can emit `contract drift`.
- Generation/check stay offline, deterministic, atomic, and non-writing in check mode. Runtime reads

- Backend workers commit only their task-owned code paths. The backend closer writes receipts but

- An implementer who finds a current seam different from the exact files and symbols below reports
  the conflict instead of silently adapting the approved design.
