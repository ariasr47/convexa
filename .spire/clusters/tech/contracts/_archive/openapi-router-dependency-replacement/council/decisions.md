# R3 decisions — OpenAPI router dependency replacement

No product conflict requires an operator ruling. The user already chose the immediate repository-owned integration replacement over waiting for an upstream release.

## Technical reconciliation

1. **Evidence-bounded advisory language.** The feature removes the dependency chain responsible for the named `RUSTSEC-2024-0436` **unmaintained advisory**. Contracts and diagnostics must not call the chain vulnerable or claim the repository is secure, safe, vulnerability-free, dependency-free, or free of every advisory.
2. **Build-graph removal, then runtime preservation.** `utoipa-axum` and `paste` are compile-time packages. Their absence is proven in manifests, `Cargo.lock`, and the locked resolved Cargo graph before build. The resulting production binary must then start and pass existing probes; no meaningless “package unavailable at runtime” claim is permitted.
3. **Inventory wording.** The preserved set is exactly `52 source-derived production operations` (or `the existing 52-operation runtime/contract inventory`), not `52 public operations`; each operation retains its existing access classification.
4. **Closed construction diagnostics.** Empty or unsupported method metadata, duplicate path-method registration, and duplicate operation identity are typed invalid-graph states reported under the existing `incomplete contract coverage` category with a safe identifier. Unexpected construction panic, serialization failure, or exporter-process failure remains `generation tooling failure`. `unsupported schema construct` remains reserved for an actual schema-representation rejection, and `contract drift` remains reserved for a completed byte comparison.
5. **Documentation stability.** Active documentation remains byte-identical unless the implementation makes a live instruction factually false; then only that sentence may use the neutral wording `The repository-owned route/OpenAPI integration is built on Axum and utoipa.` Historical archived contracts are not rewritten.
6. **Mechanism boundary.** Use one repository-owned route package per production registration, containing the handler path plus the matching pinned-`utoipa` generated `__path_*` metadata type. One consuming `ContractRouter` call installs the Axum method router and merges the same package into OpenAPI. A pairing-bijection guard and mutations must make swapped, missing, duplicated, or misnamed pairs fail. No second method/path list, local proc-macro crate, vendored general-purpose router, or hand-authored OpenAPI operation inventory is accepted.
