## 1. Goal + scope

Give the research operator a **URL-only, off-shell** corpus browser so already-kept session books are usable in a normal week without a CLI binge, without a trader session, and without pretending a stored book is live market. The operator types `/_ops/research`, supplies a sitting **API origin** plus the **metrics token**, lists SPY (and QQQ / IWM) session books, opens one dated book as a digested research read with **zero Massive**, and reads today’s coverage cells on one partitioned card. `present` means a loadable `LiveMassive` body only. `Authorizes: nothing`. This is **not** `/lab`, **not** a trader nav item, **not** a Pages proxy of `_research`, **not** score-lab HTTP, **not** replay, **not** a morning note.

Human product ruling **A (2026-08-31).** v1 on `/_ops/research` is session-books list+digest **plus** one **partitioned** coverage card (existing coverage GET, server-default date). Coverage speaks only its closed deck (`present` | `missing` | `unreadable` | `not yet due` | `blocked occupancy`); `present` is a loadable `LiveMassive` body only. The books table prints `source` verbatim and **never** grows a `present` / `kept` column. Do not mint coverage cells from list `source`. Tape / snapshots / flat-files stay out of v1 chrome. Local matrix is `Evidence: this process`, not hosted/CI coverage. No CLI `[PASS]` line on this screen. Reasoning: occupancy honesty cannot mint `present` from list provenance; omitting the coverage sibling while still needing today’s live-paid claim would push operators to read `source: live_massive` as `present`. Mixing decks is a unified status column, not a second existing GET with its own closed lookup.

## 2. Architecture

This slice is a **frontend-only operator page** over **already-shipped** research GETs. It does not capture, recompute, replay, or score. Session-archive books are the spine; archive-coverage is the one admitted sibling occupancy read. Public `/lab` stays instrument demos with synthetic data. Score-lab stays clap. Day replay stays process-start on the existing ticker SSE.

Parse **before** network (trim, then first match):

| Arm | Predicate | Network? |
|---|---|---|
| OriginEmpty | missing / whitespace-only | no |
| OriginPagesHost | parsed host is `pages.dev` or ends with `.pages.dev` (ASCII case-insensitive) | no |
| OriginUnusable | not an absolute URL; userinfo / query / fragment; path other than empty or `/`; scheme not `https`, except `http` **only** when host is loopback (`127.0.0.1`, `localhost`, `::1`) | no |
| *(usable)* | `https` (any non-Pages host) or loopback `http` | may fetch |

Canonical form: scheme + lowercased host + non-default port; strip trailing slash; **no path**. Existing research path tails are appended by the client. Relative `/api/_research` is poison even when local Vite would 200 it (that hides the Pages wall). Empty token → **omit the header**, do not skip origin, do not skip the form. A research GET is illegal until a usable sitting base exists.

**Request classifier** (first match; UX owns strings in §4). Origin-blocked is a property of the **research base / request URL**, not of dashboard `location.host`. A Pages-hosted `/_ops/research` document is allowed; it still cannot same-origin list/open.

**Classified occupancy 500** = HTTP 500 JSON whose `error` is exactly `session_archive_not_storing` or `session_archive_store_error` or `session_book_unreadable` (closed bodies in INTERFACE). **Unclassified 5xx** = any other HTTP 5xx (non-JSON, missing `error`, or an `error` token outside that closed set).

| Arm | When | Must not be classified as |
|---|---|---|
| OriginEmpty / OriginPagesHost / OriginUnusable | §2 parse fail | 401, empty-list, CORS, Function 404, occupancy |
| OriginRelative404 | request URL is path-only **or** request origin equals the document origin **and** that host is Pages. Client must not emit this; if a fetch still happens, Function 404 lands here | empty-list, LoadMiss |
| OriginCors | `fetch` rejects with **no HTTP status** **and** the view-model has a **non-opaque CORS classification**. A bare `TypeError` is **unclassified** (cold list → offline; warm **list** same-chip Retry → stale; coverage any sitting → coverage-unavailable), not this arm. Classification in this repo is an **injected test double** (or an equivalently non-opaque CORS signal). Tests must not paint cors-fault copy from an unclassified TypeError | empty-list, 401, origin-blocked, **stale keep-last** |
| Unauthorized | HTTP 401 `error: metrics_unauthorized` (missing and wrong token are the **same** class) | empty-list, origin-rejected, origin-blocked |
| OriginPages404 | HTTP 404 whose body is **not** load-miss JSON `error: "no_session_book"` (Function plaintext `Not Found` or any non-JSON 404 of this prefix) | empty-list, LoadMiss, OriginPagesHost (pre-network) |
| EmptyList | HTTP 200 list, `store: "miss"`, `count === 0`, `books: []`, no-session-book framing | any Origin* arm, 401, not-storing, list store-error, stale |
| LoadMiss | HTTP 404 JSON `error: "no_session_book"` | origin-blocked, EmptyList, coverage `missing` |
| NotStoring | HTTP 500 JSON `error: "session_archive_not_storing"` (list, load, or coverage) — **cold or warm** | empty-list, origin-blocked, stale keep-last, three `missing` cells |
| ListStoreError | HTTP 500 JSON `error: "session_archive_store_error"` (list or coverage) — **cold or warm** | not-storing, empty-list, origin-blocked, stale keep-last |
| Unreadable | HTTP 500 JSON `error: "session_book_unreadable"` (load) — **cold or warm** | LoadMiss, origin-blocked, stale keep-last digest |
| InvariantFault | HTTP 200 list **or** load **or** coverage with `vendor_called` true or `authorizes` ≠ `nothing` | digest, occupancy, empty-list, stale keep-last |
| Coverage-unavailable | origin already committed and not blocked; coverage GET fails as transport / unclassified TypeError / unclassified 5xx that is **not** not-storing / **not** store-error / not 401 / not family-404 / not classified CORS — **cold or warm, including after a prior successful coverage GET this sitting**. Prior matrix **not** kept | origin-blocked; three `missing` cells; coverage withheld; **stale keep-last**; a kept success matrix |
| *(ready / unparseable-date)* | unparseable `et_date` 422; otherwise a legal 200 for that envelope | any Origin* arm |

**Warm vs cold.** Regions classify **independently**. List key = selected books chip (SPY / QQQ / IWM). Coverage key = this sitting’s coverage GET (trio; **not** chip-keyed). Digest key = the open `(symbol, et_date)` identity.

- **Cold** for a region = no prior successful body for **that region key** in this sitting.
- **Warm** for a region = a prior successful body for **that same region key**, committed origin unchanged.

Warm-by-key does **not** by itself authorize stale keep-last. Named standing **stale keep-last (AC-30)** is **list-region only**: the selected chip is **unchanged**, that symbol’s last list is **still showing**, and a **Retry** of that list GET fails as unclassified network / TypeError / unclassified 5xx. Coverage has **no** stale path and **no** stale chip. The only stale copy on this screen is list-keyed **`Couldn't refresh — keeping the last list.`**

Chip-switch (symbol chip tap) and coverage `present` **chip-follow** **change the list key**. That action is **not** a same-symbol Retry and **must not** use AC-30 — including when the newly selected symbol already succeeded earlier this sitting (warm-by-key re-entry). Hide the currently showing books rows **and** any digest whose identity.symbol ≠ the new chip **immediately**, then fire a new list GET. Unclassified fail of that GET is books-region **`Session archive readout unavailable.`** — **not** restore of a previously hidden list of that symbol. A later chip-unchanged Retry while that symbol’s list is **showing** may be AC-30.

- **Classified CORS (cold or warm, any region)** → **cors-fault**. Title **`Cross-origin request blocked`**. **Hide** the corpus body (list, coverage card, digest). Do **not** apply stale keep-last. Do **not** show **`Couldn't refresh — keeping the last list.`** Abort of an in-flight load is not OriginCors.
- **Classified occupancy 500 (cold or warm)** → paint **that** arm: not-storing (AC-27) / list store-error (AC-53) / unreadable (AC-29) / coverage withheld (AC-39). **Hide** the prior success body for the region that returned the occupancy 500. A **list** occupancy 500 is page-level AC-27 / AC-53: **list-occupancy exclusive standing** — no books table, **no** success coverage matrix, **no** concurrent load digest, **no** concurrent load-fault Alert. Do **not** apply stale keep-last. A warm Retry that returns `session_archive_not_storing` is AC-27, never AC-30.
- **Later family-404** of the committed origin → **origin-blocked**: hide the corpus body (do not keep a list on a blocked origin).
- **Warm same-chip list Retry** (chip **unchanged**, last list of that symbol **still showing**) that fails as **unclassified network / TypeError** (no HTTP status, not classified CORS) **or** as **unclassified 5xx** (HTTP 5xx that is **not** a classified occupancy 500), committed origin unchanged, **not** a research-family 404 → **stale** for the **list** only: keep last **list** of that key + chip **`Couldn't refresh — keeping the last list.`** Stale keep-last does **not** apply to classified CORS, family-404, classified occupancy 500, chip-switch / chip-follow (including warm-by-key re-entry), **or any coverage GET**.
- **Coverage GET** that fails as unclassified network / TypeError / unclassified 5xx (not 401, not family-404, not classified CORS, not classified occupancy 500) → **coverage-unavailable (AC-38) always** — cold or warm, first fetch or Retry after a successful matrix this sitting. Books stay when the list envelope is legal. **No** success matrix. **No** keep-last of the prior matrix. **No** stale chip. Classified occupancy 500 of coverage is **coverage withheld (AC-39)**, not this arm.
- **Chip-switch / chip-follow list GET** that fails → **that new symbol’s** arm; **never** the previous symbol’s rows under the new chip; **never** the stale chip as a way to keep the old list; **never** AC-30 restore of a previously hidden list of the re-entered symbol. Empty-200 → empty-list for the new symbol; coverage **remains** if it already succeeded. Unclassified network / TypeError / unclassified 5xx → books-region **`Session archive readout unavailable.`**; coverage **remains** if it already succeeded and did not itself fail. Classified occupancy 500 → page-level not-storing / list store-error (AC-27 / AC-53): list-occupancy exclusive standing. 401 / family-404 / classified CORS → those page-level arms (corpus hidden as specified).
- Cold unclassified transport (first list this sitting, no prior list body for any symbol) → **offline** (AC-17), not stale, not cors-fault.

Cors-fault, classified occupancy 500, coverage-unavailable, and stale keep-last are mutually exclusive **meanings**. List stale and coverage-unavailable **may appear together** as independent regions (stale chip on the list + nested `Coverage readout unavailable.`) — the list chip never means a kept coverage matrix. Chip-switch is not a warm Retry and cannot use AC-30 to keep another symbol’s rows or to restore a hidden same-symbol list. A warm CORS failure cannot be both the cors-fault Alert and the stale chip. A warm not-storing 500 cannot be both AC-27 and AC-30. A warm coverage unclassified fail cannot be both AC-38 and a kept success matrix. A QQQ chip cannot show SPY rows via AC-30.

**404 split is load-bearing.** List empty is **200**. Load miss is **404 JSON** `no_session_book`. Pages Function 404 is **404 plaintext** `Not Found`. Treating status 404 as one bucket would call “no Friday book” origin-blocked, or call a Function wall an empty week.

**Coverage GET** issues only after origin is committed and not rejected/blocked. An origin arm **withholds** the matrix (zero cells, not three `missing`). Coverage-only fault after a good list is nested, not a page origin class. Classified CORS of the coverage GET (same sitting base as list) is **page-level cors-fault**, not nested coverage-unavailable. Coverage classified occupancy 500 is **coverage withheld**, not coverage-unavailable and not stale keep of the last matrix. Coverage unclassified transport / TypeError / unclassified 5xx is **always coverage-unavailable**; the prior matrix is **not** kept.

**Two closed decks — not aliases.**

- **Book inventory row** (list): identity `(symbol, et_date)` + `source_as_of` + `source` ∈ `{live_massive, fixture, session_tape}` (unknown wire → unavailable; print verbatim; never `present`). List `store: miss` + empty `books` = checked, none for that symbol.
- **Book load digest** (one load): same identity + source + `source_as_of`; cardinality labels only (`daily_bars` / `minutes` / `trades` / `market.contracts` **counts**). Raw arrays are not a UI structure and are never serialized to a file from this surface.
- **Coverage matrix** (existing coverage read): server trio; per-row `cell` ∈ `{present, missing, unreadable, not yet due, blocked occupancy}`; `present` **only** here, **only** loadable `LiveMassive`. `last_readable` is the payload string (closed `{SYMBOL} {ET_DATE}` / `none (seed fixture excluded)` / `undetermined (walk cap)`). Envelope `evidence` stays `this process`. `authorizes` remains `nothing`.

**Envelope invariant-fault.** `vendor_called` true or `authorizes` ≠ `nothing` on a **200 list, load, or coverage** envelope is **invariant-fault** for **that envelope**, not a digest, not occupancy, not stale keep-last. Title is always **`invariant-fault`**. Body is **envelope-scoped** (§4) — load copy is not reused for a list or coverage envelope. A list invariant-fault hides the books table (do not print rows from an illegal list). A coverage invariant-fault is nested on the coverage card when the list envelope is legal. A load invariant-fault is the digest-region arm (same as a list-driven open).

**Coverage `present` vs load disagreement.** A `present` cell means the **coverage GET** reported a loadable `LiveMassive` identity. Clicking it always issues that identity’s load GET. If the load is `no_session_book` / unreadable / invariant-fault, the **digest region** shows that load-fault arm (same copy as a list-driven open of the same fault) **unless** a concurrent list GET on chip-follow is page-level occupancy 500 — then **list-occupancy exclusive standing** hides this digest-region arm. Do **not** mint coverage `missing` from the load 404, do **not** drop or rewrite the cell, do **not** keep a success digest. The cell stays the coverage GET’s token until a later coverage GET.

**List-occupancy exclusive standing.** When the **list** GET returns classified occupancy 500 (`session_archive_not_storing` / `session_archive_store_error`), AC-27 / AC-53 is the **only** operator standing: no books table, no success coverage matrix, **and no digest or load-fault Alert from any concurrent load GET** (including a coverage `present` chip-follow that issued list GET + load GET in parallel). A success digest must not appear under `session archive not storing` or `session archive store error:`. If the load GET settles first, replace it: the final paint is the occupancy 500 Alert alone.

**Retry fan-out** (operator-initiated; not a 60s poll):

| Control | When it is shown | GETs re-issued | Never |
|---|---|---|---|
| Page **`Retry`** | cors-fault; cold list offline (AC-17); chip-switch / chip-follow books-region offline; list stale (AC-30); not-storing (AC-27); list store-error (AC-53); coverage-unavailable (AC-38); coverage withheld (AC-39); list or coverage invariant-fault | **List GET** for the currently selected chip **and** **coverage GET** | Load GET; relative `/api/_research`; auto-poll |
| Digest-region **`Retry`** | Load unreadable or load invariant-fault **and** page standing is **not** AC-27 / AC-53 / cors-fault / origin-* / 401 | **That identity’s load GET only** | List GET; coverage GET |
| **Unlock** | Locked / origin-rejected / 401 | First usable commit: list (default or selected chip) + coverage | Load GET |
| Chip tap / chip-follow list | Symbol change | **List GET** for the new chip. Chip-follow **also** issues the `present` identity’s **load GET** | Coverage GET (coverage stays the trio until page Retry / Unlock) |
| Open dated row / `present` of the already-selected symbol | Operator click | **Load GET** of that identity only | Extra list GET; coverage GET |

Coverage-unavailable is therefore **not** a dead letter: page Retry **always** includes a coverage GET. A coverage GET from that Retry that fails as unclassified transport / TypeError / unclassified 5xx is **AC-38** even when a coverage matrix previously succeeded this sitting (prior matrix not kept). It is **not** AC-30.

**Data flow.** Operator types `/_ops/research` → locked chrome, **no GET**. Unlock with a usable origin → parallel GET list (default SPY) + coverage (server-default date) against committed origin. Symbol chip → **immediately hide** the previous symbol’s book rows **and** any digest whose identity.symbol ≠ the new chip; fire a **new list GET** for the selected symbol; show books-region in-flight until that GET settles; coverage stays the trio. Open a dated row → one load GET (previous load aborted). Open a coverage **`present`** cell → one load GET (previous load aborted) **and**, when that cell’s symbol is not the selected books chip, a **chip-follow**: the selected chip becomes that symbol, previous symbol’s rows **and** digest are hidden, and a **new list GET** fires for it (same as tapping the chip) **in parallel with** the load GET. A `present` click for the already-selected symbol is **load GET only** — no extra list GET; the current symbol’s rows may remain. The books table **must not** keep another symbol’s rows under the new chip — not in-flight, not after the new list fails, not via stale keep-last. Failed list GET for the new symbol is **that** symbol’s empty / error / not-storing / list store-error / offline — never SPY rows under a QQQ chip. If that chip-follow list GET is occupancy 500, **list-occupancy exclusive standing** hides the parallel load outcome. No Massive. No trader routes. No auto-poll (on-demand: Unlock, symbol change, Retry as tabled above, open).

**CORS (lane-check, verified 2026-08-31).** Production `production_cors_layer` exact-matches **`ALLOWED_BROWSER_ORIGINS`**; live Railway lists `https://convexa.pages.dev` and already allows `Authorization` / `x-metrics-token`. Hosted weekly use from **that** document origin, after a non-Pages sitting base + metrics token, is CORS-allowed. Pages **preview** (`https://<hash>.convexa.pages.dev`) and a future custom SPA origin are **not** members — OriginCors until ops adds them. Fix is ops allowlist, not a research adapter and not a Function hole. Local Vite (`APP_ENV` ≠ prod, CORS `Any`, origin `http://127.0.0.1:8000`) is **local evidence**, not hosted Pages proof. Older deploy docs (`docs/DEPLOY_RUNBOOK.md`, `docs/CLOUDFLARE_PAGES_SETUP.md`) still name `ALLOWED_ORIGINS`. GATE Q and ops readers verify **`ALLOWED_BROWSER_ORIGINS`**. The docs name is not this slice’s allowlist key.

**Failure modes + isolation:**

- Trader path: zero new imports on ticker / positions / scanner / lab; zero SSE; this page is not inside AppShell, so a throw cannot unmount trader chrome (per-route `ErrorBoundary` already wraps lazy elements).
- Server remains the gate: a forged UI that skips the token still 401s. FE 401 handling is UX, not enforcement. A trader session cookie without the metrics token is not the gate (AC-14 is a **non-page** GATE Q probe; page fetches use `credentials: 'omit'` and do not attach that cookie).
- Pages 404 stands. `credentials: 'omit'` so a trader cookie is not attached on the operator URL’s own fetches.
- Vendor isolation: `vendor_called !== false` is invariant-fault. No retry storm.
- Score isolation: do not import `quant-engine`; do not POST recommendation; do not call ticker compute. Empty `apps/api` diff + no `convexa.ts` growth prove `[additive-keeps-score-byte-identical]`.
- Secret isolation: token is header-only; never logged; never in copy; never in the image. Origin is a public URL but still not hardcoded and not copied into Alerts / aria / title.
- Occupancy isolation: coverage `present` never applied to a book row, tape, extract, or fixture. ## 4. UI + interaction

**Flows:**

1. Operator types `/_ops/research` (not a nav click). Off-shell chrome paints immediately. **Locked.** No GET.
2. Types **API origin** (+ **Metrics token** if this API requires it) → **Unlock**.
3. Client reject (empty / `*.pages.dev` / unusable) → **origin-rejected**, no GET, no relative fallback. Focus → origin field.
4. Else commit origin (+ token if non-empty) → parallel GET list (SPY) + coverage (server-default date), metrics header pair if token non-empty, `credentials: 'omit'`.
5. Family 404 → **origin-blocked**. 401 → **unauthorized** (focus → token; origin field remains). **Classified CORS (cold or warm) → cors-fault** (corpus hidden; **not** stale). **Classified occupancy 500 (cold or warm) → not-storing / list store-error / unreadable / coverage withheld** (those arms; **not** stale). Unclassified cold fail → **offline**. Unclassified network / TypeError / unclassified 5xx on a **list GET**, **warm, same symbol, chip unchanged, last list still showing** (not CORS, not family-404, not classified occupancy 500) → **list stale keep-last** (AC-30). The same failure class on a **coverage GET** is **never** stale — flow 6. 200 empty list → **empty** (coverage may still be default). 200 with rows → **default**. List/load/coverage 200 invariant-fault → envelope-scoped **invariant-fault**.
6. Coverage-only fail after a legal list — **cold or warm, including after a prior successful coverage GET** — → nested **coverage-unavailable** (unclassified transport/TypeError/unclassified 5xx: **no** kept matrix, **no** stale chip) or **coverage withheld** (classified occupancy 500) or coverage **invariant-fault**. Books stay when the list envelope is legal. Classified CORS is page-level cors-fault (step 5), not this nested arm. Page **`Retry`** re-issues list GET + coverage GET.
7. Click a dated row → **success** digest of that identity, or the matching load-fault (load-miss / unreadable / invariant-fault). Click a coverage **`present`** cell → load GET of that identity; if the cell’s symbol ≠ selected books chip, **chip-follow** (select that chip, **hide previous rows and digest**, list GET for the new symbol **in parallel with** the load GET) then digest or load-fault **unless** the list GET is occupancy 500 (list-occupancy exclusive standing hides the load outcome). Other coverage cells do not load. A load-fault after `present` does **not** rewrite the cell.
8. Switch SPY/QQQ/IWM chip → **immediately hide** previous symbol’s book rows **and** digest; new list GET; books-region in-flight until it settles; coverage stays the trio. Failed new list is **that** symbol’s empty / error / not-storing / list store-error / offline — **never** the previous rows, **never** stale-of-old, **never** AC-30 restore of a hidden same-symbol list on re-entry.
