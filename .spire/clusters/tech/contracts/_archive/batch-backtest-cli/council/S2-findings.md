## Important  (should fix)

- **`none_replayed` artifact rule contradicts itself, so AC-12’s “records disposition `missing`” has no mandatory observable sink.** SPEC §2 data flow: “write dated artifact (when selected ≥ 1)”. Under `--as-of`, `selected = |symbols|`, so a one-symbol miss is `selected = 1`, `corpus_status = none_replayed`. INTERFACE “Research artifact schema”: written when “selected ≥ 1; refused splits and `empty_corpus` write **no** file” — implying `none_replayed` **does** write. But the corpus-status table says `none_replayed` → “Artifact **may** be written”. AC-12 (SB) requires the run “records disposition `missing`”; the token lives on `rows[].disposition` in the artifact, while the console only prints `no stored snapshot for <SYMBOL> at <as_of>`. An implementer who takes “may” and writes no file still satisfies the miss literal and fails to persist the closed token. Pick must-write (to match data flow + INTERFACE) or name the console/stderr place the token is recorded.

- **`aggregates` omit-or-empty vs a required INTERFACE key.** SPEC §2: when `corpus_status = none_replayed`, “omit score/tier/GEX aggregates (or emit empty aggregates with `replayed_count: 0`)”. INTERFACE required keys list `aggregates` on **every** written measurement artifact (“empty / `replayed_count: 0` when `none_replayed`”). Omit fails the interface; empty object fails a reader who takes SPEC’s first branch. Same ship needs one rule.

- **`opportunity_tier` is a required D-metric whose live helper is not actually score-only.** SPEC §2: “`opportunity_tier` | tier derived from that score (same desk helper the live path uses)”. The live helper is `compute_opportunity_tier(score, gate.ready, 40, 60, 80)` after `evaluate_gate` (`apps/api/src/routes/market.rs`); `prime` requires `ai_ready`. `compute_analytics_from_vendor` / `AnalyticsSnapshot` carry `signals.opportunity_score` and **no** tier (`apps/api/src/state.rs`, `apps/api/src/services/analytics.rs`). Bands, `evaluate_gate`, and `ai_ready` are unnamed. Three implementers can all “use the desk helper” and emit three `tier_counts` maps (score-only prime possible; `ai_ready = false` forever so `prime` is unreachable; full gate). AC-1 only checks the key exists, so the BRIEF’s tier measurement can silently disagree with the desk.

- **`--as-of` plus a split flag is allowed and can never satisfy D1.** `--as-of` loads one dated identity per symbol (SPEC §2: “no `list`, no window filter”). Every selected row shares that `as_of`, so `|T*| = 1`. Train `{ as_of < T }` and holdout `{ as_of ≥ T }` cannot both contain a `replayed` row. §5 usage errors name empty `--symbols`, both split flags, `--as-of` with `--from`/`--to`, and `--train-frac` ∉ (0,1) — not `--as-of` with `--split-at`/`--train-frac`. The combo always prints `split refused — cannot form two non-empty buckets` and writes no artifact. Either add it to the usage-error row or say the refuse is the specified outcome.

- **Split membership “row refs” are promised on the artifact with no inner shape.** SPEC §2 artifact schema: `split` is `{ "rule": string, "train": [row refs], "holdout": [row refs] }`. INTERFACE: `"train": array, "holdout": array`. AC-2 / AC-4 (SB) require the artifact to twin “split membership”. Refs could be row indices, `{symbol, as_of}`, or copied row objects; skipped rows “may still appear in printed membership” (SPEC §2 / AC-4) without saying whether they appear in the arrays. GATE Q cannot fail a wrong membership encoding.

- **`none_replayed` is a named run outcome with no §4 console shape.** SPEC §2: `none_replayed` is “**not** a successful measurement of scores”. §4 standing block is required on every “**successful measurement** run”; AC-18 uses the same phrase; AC-25 requires `standing` on every **written** measurement artifact. Flows item 1 dumps `ok` / `partial` / `none_replayed` into the success path (standing → rows → aggregates → closing). The component matrix has no `none_replayed` column. After the “may write” fork above, it is unspecified whether stdout gets the standing banner, omitted/empty aggregates, the closing Authorizes line, or the empty-corpus-style short path.
