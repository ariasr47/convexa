# portfolio-demo-platform — implementation plan

Build a populated, explicitly synthetic Convexa portfolio tour and source-linked atlas, then ship a verified static Pages feature preview. This is a frontend composition over the existing generated HTTP DTOs: a build-selected provider in `libs/api`, browser-local scenario/book/clock, and ticker-local lazy views. Rust, generated schema, quant math, Railway and live access gates remain unchanged. Stack: React 19, TypeScript, Vite 8, MUI, Nx 23, Vitest, Playwright, Cloudflare Pages.

These are **unchanged live endpoint shape pins**, drawn from existing generated types and the current foundations contract. They are safe anonymous GETs. When a live backend is available, `interface_conformance.mjs` can check them. A backend-unavailable run is recorded `NOT RUN` under `NO_BACKEND_CHANGE`, never called a pass.
