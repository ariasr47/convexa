Convexa Repo Atlas

Convexa reads a stock's option chain as dealer gamma structure: the call and put walls, the gamma flip, the magnet. It sets that beside public market data. One codebase builds two sites: a live site that reads real public sources through a Rust API, and a demo that runs the whole desk on one authored day inside your browser.

It follows the way you learn a codebase, in three parts. I · Where everything is: the map, a walk through every file from the root, and which files to open for any change. II · What happens on startup: a recorded, step-by-step replay of startup and of five everyday actions (every mount, re-render, request and storage write), then who owns what. III · How it is built and checked. Folders, files and components all link to each other, in the same colours.

        08 · Who owns what

        What renders first, and what each layer owns

        Outermost first, exactly as nested in code. Bold words are the state a node owns or the endpoint it reads. Click a node to fold it.

          Stores outside React context

          Module-level stores read with useSyncExternalStore, so any component can subscribe without a provider: liveTapeStore (pages/ticker/liveTapeStore.ts:126), positions (usePortfolio.ts:124), orders (useOrders.ts:377), alerts (useAlerts.ts:98). useMarketDataMode keeps one shared promise per page load.

          No data library

          No TanStack Query, SWR, Redux or Zustand. Two home-made patterns: usePollingResource keeps the last data on error, pauses while the tab is hidden, aborts on key change, and haltOn stops it for good; useRead reads once per key. shared/hooks/usePollingResource.ts:21-177.

          10 · Inside the API

          From api-rust serve to a listening socket

          The Rust service in is one binary with 21 top-level subcommands; serve is the web API.

            A request's path through the server

            TraceLayer → CORS (production: exact origins from ALLOWED_BROWSER_ORIGINS, with credentials) → rate_limit_middleware → handler. Auth is not a layer: each protected handler asks for the signed-in user itself, through the AuthUser extractor, or require_user where its body must parse first (routes/auth.rs:1082-1113). The API adds no compression, timeout or security-header layers; the edge supplies the headers. server.rs:284-374; apps/api/Cargo.toml:53.
